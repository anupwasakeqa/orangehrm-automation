# OrangeHRM Automation Framework

## Project Overview

This project is an automation testing framework for the OrangeHRM application using Selenium WebDriver, Java, TestNG, and Maven.

## Application

Base URL: https://opensource-demo.orangehrmlive.com

## Technologies Used

- Java
- Selenium WebDriver
- TestNG
- Maven
- Eclipse
- Git & GitHub

## Framework

- Page Object Model (POM)
- TestNG
- Maven

## How to Run

1. Clone the repository.
2. Import the project into Eclipse as a Maven project.
3. Update Maven dependencies.
4. Run the TestNG test suite.

## Test Suite

The TestNG suite is available in:

`testng.xml`
